dsh-rewind

DeepSeek Harness 会话回退插件

随时回退 · 打断思考 · 编辑重发
dsh — DeepSeek Harness
↺ 已回退到一条历史消息（可编辑）。发送后将从此处继续；点右侧 ✕ 取消回溯。
dsh — 打断运行中的模型
↺ 已回退并打断当前思考。输入框中是回退的消息内容，可编辑后发送。
↺

一键回退

每条用户消息旁有回退图标，点击即回退到该消息，后续内容从聊天视图和模型上下文中消失。

⚡

打断思考

回退时若模型正在思考，立即中断当前回合，保留排队消息，从截断点继续。

✏️

编辑重发

回退消息自动填入输入框，可编辑后发送。模型只看到截断后的历史 + 新消息。

✕

取消回溯

发送前随时取消，隐藏消息恢复显示，对话继续原状。无任何副作用。

📝

日志完整

会话日志从不删除原始消息。每次状态变化追加审计记录，跨重启可恢复。

📦

永久插件

零依赖、零构建步骤。安装后每次 DSH 启动自动加载，无需手动配置。

双面架构

🖥️ Host 半

  • ESM Cordis 插件
  • webServer 路由（RPC）
  • agent/pre-step 瀑布
  • Session 表面过滤
  • hook/invoked 审计
⟷

🌐 Client 半

  • __ModuleLoader__ 包
  • Slot 注册（keyed/list）
  • CSS 动态隐藏
  • React + UI 原语
  • inputActions 交互

工作流程

① 用户点击 ↺ → 标记目标消息
Host 追加 hook/invoked { phase: 'mark' }
如模型正在运行 → agent.cancel 立即中断
② 客户端更新 → 输入框填入消息内容
CSS 隐藏目标及后续所有消息
横幅提示：「已回退到一条历史消息」
③ 用户发送（可编辑后）→ 提交隐藏区间
Host 追加 hook/invoked { phase: 'commit' }
deriveMessages() 按区间过滤 → 模型只看到截断历史
④ 取消回溯？ → 点 ✕ → Host 追加 cancel 记录
CSS 移除隐藏规则 → 消息全部恢复显示

# GitHub

# 本地路径
